========================================
أوامر Git لرفع الملفات الجديدة
========================================

الخطوة 1: أضف الملفات الجديدة
------------------------------------------
git add lib/services/cameraScreenshotService.ts
git add components/cameras/CameraPlayer.tsx
git add lib/api/genderAi.api.ts
git add AI_SCREENSHOT_FIX.md
git add ERRORS_AND_SOLUTIONS.md
git add FINAL_SUMMARY.md

أو (أضف كل شيء):
git add .

الخطوة 2: تحقق من الملفات المضافة
------------------------------------------
git status

الخطوة 3: اكتب رسالة الـ Commit
------------------------------------------
git commit -m "Fix camera screenshot service and AI integration

- Create cameraScreenshotService for periodic camera screenshot capture
- Update CameraPlayer to use the new screenshot service
- Add detectGender() helper method to genderAi.api
- Add comprehensive documentation for errors and solutions
- Implement automatic screenshot sending to AI backend"

الخطوة 4: رفع للـ GitLab
------------------------------------------
git push

أو إذا كان أول مرة:
git push -u origin feature/digital-signage-docker

الخطوة 5: تحقق من الرفع
------------------------------------------
git log --oneline
(يجب أن ترى آخر commit في القمة)
